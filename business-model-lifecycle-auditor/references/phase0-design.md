### Step 0: Business Model Canvas Selection & Design

#### Framework Selection

| Situation | Canvas | Time |
|-----------|--------|------|
| New idea | Lean Canvas | 20-30 min |
| Existing business, map it | Business Model Canvas (BMC) | 1-2 hrs |
| Validate product-market fit | Value Proposition Canvas (VPC) | 30-60 min |
| Existing + pivot | BMC (current) → Lean Canvas (new) | 2-3 hrs |

#### Canvas A: Lean Canvas (startups)

```
┌──────────────┬─────────────┬──────────────┬─────────────┬──────────────┐
│   PROBLEM    │  SOLUTION   │   UNIQUE     │   UNFAIR    │  CUSTOMER    │
│   (Top 3)    │  (Top 3)    │   VALUE      │  ADVANTAGE  │  SEGMENTS    │
│              │             │ PROPOSITION  │             │              │
│  Existing    ├─────────────┤              ├─────────────┤              │
│  alternatives│  KEY        │              │  CHANNELS   │              │
│              │  METRICS    │              │             │              │
├──────────────┴─────────────┴──────────────┴─────────────┴──────────────┤
│       COST STRUCTURE        │            REVENUE STREAMS               │
└─────────────────────────────┴──────────────────────────────────────────┘
```

| Block | Key Question | Common Mistake |
|-------|-------------|----------------|
| Problem | Top 3 customer problems? | Listing features, not problems |
| Customer Segments | Who has this most acutely? | "Everyone" |
| Unique Value Proposition | Why choose you? One sentence. | Vague or feature-focused |
| Solution | Simplest thing that solves it? | Over-building before validating |
| Channels | How will you reach them? | "Build it and they will come" |
| Revenue Streams | How will you make money? | Not testing WTP early |
| Cost Structure | Main costs? | Forgetting founder time |
| Key Metrics | 1-3 health indicators? | Vanity metrics |
| Unfair Advantage | Can't be copied or bought? | Confusing first-mover with moat |

**Lean Canvas Fill Order** (per Ash Maurya — order matters):
1. **Customer Segments** → 2. **Problem** → 3. **Unique Value Proposition** → 4. **Solution** → 5. **Channels** → 6. **Revenue Streams** → 7. **Cost Structure** → 8. **Key Metrics** → 9. **Unfair Advantage**

⚠️ Always Problem before Solution. Founders who start with Solution build things nobody needs.

#### Canvas B: Business Model Canvas (existing businesses)

```
┌──────────────┬─────────────┬──────────────┬─────────────┬──────────────┐
│     KEY      │     KEY     │    VALUE     │  CUSTOMER   │   CUSTOMER   │
│   PARTNERS   │  ACTIVITIES │ PROPOSITION  │RELATIONSHIPS│   SEGMENTS   │
│              ├─────────────┤              ├─────────────┤              │
│              │     KEY     │              │  CHANNELS   │              │
│              │  RESOURCES  │              │             │              │
├──────────────┴─────────────┴──────────────┴─────────────┴──────────────┤
│       COST STRUCTURE        │            REVENUE STREAMS               │
└─────────────────────────────┴──────────────────────────────────────────┘
```

**BMC Fill Guide:**

| Block | Key Question | What to Capture |
|-------|-------------|-----------------|
| Customer Segments | Who creates the most value? | Rank by revenue/potential |
| Value Proposition | What problem do we solve per segment? | Per-segment value delivered |
| Channels | How do we reach, sell, deliver? | Awareness → Purchase → After |
| Customer Relationships | What does each segment expect? | Personal / automated / self-serve / community |
| Revenue Streams | What are customers paying for, how? | Each stream + pricing mechanism |
| Key Resources | What assets are essential? | Physical, intellectual, human, financial |
| Key Activities | What must we do exceptionally well? | Production, problem-solving, platform |
| Key Partners | Who do we need? | Alliances, suppliers, JVs |
| Cost Structure | What are the biggest costs? | Fixed vs. variable, economies of scale |

**BMC Fill Order** (per Osterwalder — start from the customer, work left):
1. **Customer Segments** → 2. **Value Proposition** → 3. **Channels** → 4. **Customer Relationships** → 5. **Revenue Streams** → 6. **Key Resources** → 7. **Key Activities** → 8. **Key Partners** → 9. **Cost Structure**

⚠️ Start right (customer), move left (infrastructure). Revenue before costs — understand what creates value before mapping what it costs.

#### Canvas C: Value Proposition Canvas (product-market fit)

```
┌─────────────────────────────────────────────────────────────────────┐
│   VALUE MAP                              CUSTOMER PROFILE           │
│   ┌──────────────────┐                   ┌──────────────────┐      │
│   │  Products &      │                   │  Customer Gains  │      │
│   │  Services        │                   │                  │      │
│   ├──────────────────┤      FIT?         ├──────────────────┤      │
│   │  Gain Creators   │  ◄────────────►   │  Customer Jobs   │      │
│   ├──────────────────┤                   ├──────────────────┤      │
│   │  Pain Relievers  │                   │  Customer Pains  │      │
│   └──────────────────┘                   └──────────────────┘      │
└─────────────────────────────────────────────────────────────────────┘
```

Start with RIGHT side (Customer Profile) first.

**VPC Fill Guide:**

| Customer Profile (Right) | Questions |
|--------------------------|-----------|
| **Customer Jobs** | What functional, social, or emotional jobs are they trying to do? |
| **Pains** | What annoys them before, during, after getting the job done? What risks do they fear? |
| **Gains** | What outcomes do they want? What would delight them? |

| Value Map (Left) | Questions |
|-------------------|-----------|
| **Products & Services** | What do you offer that helps them get the job done? |
| **Pain Relievers** | How exactly do you eliminate or reduce their pains? |
| **Gain Creators** | How exactly do you create their desired gains? |

#### Workflow: New Idea
```
1. Lean Canvas (20 min) → 2. VPC (top segment) → 3. Customer interviews (5-10) → 4. Iterate canvas → 5. Phase 1 when paying customers → 6. BMC when scaling
```

#### Workflow: Existing Business Pivot
```
1. BMC (current) → 2. VPC (find weak fit) → 3. Lean Canvas (new initiative) → 4. Phase 1 (audit new model) → 5. BMC (future state)
```

### Step 1: Value-Market Fit Validation

> **6 Questions:**
> 1. What job is the customer hiring your product to do? (In their words)
> 2. Top 3 pains before/without your solution?
> 3. Which pains does your product actually relieve?
> 4. What gains does your product create?
> 5. Gap between what you THINK you sell and what customers THINK they buy?
> 6. If your product disappeared, what would customers use instead?

**Fit Scoring:**

| Signal | Score | Meaning |
|--------|-------|---------|
| Customers can't articulate what you do | 1/10 | No fit |
| Understand but find alternatives easily | 3/10 | Weak — commodity |
| Find value but don't prioritize it | 5/10 | Nice-to-have |
| Rely on it and would miss it | 7/10 | Strong fit |
| Evangelize and can't go back | 9/10 | PMF achieved |
| Pay premium, expand, bring others | 10/10 | Market pull |

**Sean Ellis Test:** "How would you feel if you could no longer use [product]?" — 40%+ "Very disappointed" = PMF.

**Fit-Gap Analysis:**

| Customer Job / Pain / Gain | Your Solution | Fit (1-5) | Gap |
|---------------------------|---------------|-----------|-----|
| [Job 1] | [How you address it] | X | [What's missing] |
| [Pain 1] | [How you relieve it] | X | [What's missing] |
| [Pain 2] | [How you relieve it] | X | [What's missing] |
| [Gain 1] | [How you create it] | X | [What's missing] |

**⚠️ Hard Gates:**
* Score < 5 → STOP. Go back to canvas. No audit fixes a product nobody needs.
* Score 5-6 → Proceed but flag fit as a risk.
* Score 7+ → Proceed confidently.

### Step 2: Revenue Model Classification & Mapping

> **9 Questions:**
> 1. How do you make money?
> 2. Average revenue per customer?
> 3. Cost to acquire a customer?
> 4. Cost to deliver?
> 5. Hours YOU spend per customer?
> 6. Business type?
> 7. Value metric? (seat / usage / project / access / transaction)
> 8. Billing cadence?
> 9. Sales motion? (PLG / Sales-led / Channel / Hybrid)

**Revenue Model Classification:**

| Model | Key Metric | Scale Pattern |
|-------|------------|---------------|
| **Subscription (SaaS)** | MRR/ARR, NRR | Compounds |
| **Usage-Based / API** | Revenue & margin per unit | Margin risk |
| **Credit-Based** | Utilization, expiry, repurchase | Predictable |
| **Marketplace** | GMV, take rate, liquidity | Network effects |
| **Productized Service** | Delivery cost, throughput | Linear unless systematized |
| **Custom Service / Agency** | Utilization, effective hourly | Founder-dependent |
| **Info Products / Courses** | CAC, completion, refund rate | High margin |
| **E-commerce / DTC** | AOV, repeat purchase, COGS | Inventory risk |
| **Transaction Fee** | Volume, fee %, retention | Customer growth |
| **Ads / Sponsorship** | CPM, audience, engagement | Attention risk |
| **Outcome-Based** | Success rate, value of outcome | Measurement challenge |
| **Hybrid** | Identify dominant model | Complexity risk |

**Sales Motion Classification:**

| Motion | Pricing Implications |
|--------|---------------------|
| **PLG** | Price transparency, usage tiers, fast payback |
| **Sales-Led** | Custom pricing ok, longer payback, discount risk |
| **Channel** | Margin sharing, partner economics |
| **Hybrid** | Separate unit economics per segment |

**Model Summary Template:**

| Metric | Current | Formula |
|--------|---------|---------|
| Revenue Model | [Type] | From classification |
| Value Metric | [What they pay per] | Seat / Usage / Access / Transaction |
| Billing Cadence | [Monthly/Annual/etc.] | |
| Sales Motion | [PLG/Sales-led/etc.] | |
| Revenue/Customer | $X | Price × Units |
| CAC | $X | Marketing Spend / New Customers |
| Delivery Cost | $X | Direct costs per customer |
| Gross Margin | X% | (Revenue - Delivery) / Revenue |
| Your Hours/Customer | X hrs | Your time invested |
| Effective Hourly Rate | $X | Profit / Your Hours |
